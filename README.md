# Das Kapital: Chapter Explanations

An analytical guide, reading companion, and interactive simulation platform covering all three volumes of Karl Marx's *Capital* (110 chapters).

---

## How to Access the Files

### 1. Read Online
You can read the entire collection directly in your web browser:

👉 **[https://Lenins-Hat.github.io/Capital-Chapter-Explanations/](https://Lenins-Hat.github.io/Capital-Chapter-Explanations/)**

---

### 2. Read Offline (Local Files)
All assets are self-contained with no external dependencies or internet connection required:

1. Clone or download this repository:
   - **Download**: Click the green **Code** button above and select **Download ZIP**, then extract the files.
   - **Git**:
     ```bash
     git clone https://github.com/Lenins-Hat/Capital-Chapter-Explanations.git
     ```
2. Double-click **`index.html`** in the root directory to open the main portal in any web browser.
3. Alternatively, navigate directly into any volume folder and open individual chapter explanation files:
   - `Volume 1/Chapter [N]/`
   - `Volume 2/Chapter [N]/`
   - `Volume 3/Chapter [N]/`
